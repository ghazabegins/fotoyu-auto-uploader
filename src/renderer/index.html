Panduan Sesuai Kamera

Cara Menghubungkan Kamera Nikon (Z Series & DSLR)

  1. Colokkan kabel USB-C dari kamera Nikon ke laptop.
  2. Buka menu kamera: Menu Setup (ikon kunci) ➔ USB ➔ Pilih MTP (atau Mass Storage).
  3. Status di aplikasi akan berubah menjadi Terhubung. Mulai memotret, foto langsung otomatis terupload!

Cara Menghubungkan Kamera Sony (Alpha, A7, A9, FX Series)

  1. Colokkan kabel USB-C dari kamera Sony ke laptop.
  2. Buka menu kamera: Menu ➔ USB Connection ➔ Pilih Mass Storage (atau PC Remote).
  3. Status di aplikasi akan berubah menjadi Terhubung. Mulai memotret, foto langsung otomatis terupload!

Cara Menghubungkan Kamera Canon (EOS R & DSLR)

  1. Colokkan kabel USB dari kamera Canon ke laptop.
  2. Nyalakan kamera. Jika muncul pilihan di layar kamera, pilih Photo Import / Sambungkan ke PC.
  3. Status di aplikasi akan berubah menjadi Terhubung. Mulai memotret, foto langsung otomatis terupload!

Cara Menghubungkan Kamera Fujifilm (X Series & GFX)

  1. Colokkan kabel USB dari kamera Fujifilm ke laptop.
  2. Buka menu kamera: Menu ➔ Connection Setting ➔ Connection Mode ➔ Pilih USB Card Reader (atau PC Auto Save).
  3. Status di aplikasi akan berubah menjadi Terhubung. Mulai memotret, foto langsung otomatis terupload!

Pertanyaan Sering Ditanyakan (FAQ & Kendala Lapangan)

Mengapa Kamera Nikon / Sony / Canon saya belum terdeteksi saat dicolok kabel USB?

Pastikan pengaturan mode USB di menu kamera diatur ke MTP / PTP atau Mass Storage (bukan mode Charging atau Webcam). Gunakan kabel USB data bawaan berkualitas baik dan pastikan kamera dalam posisi menyala (ON).

Mengapa muncul pesan "Duplicate Signature / Foto Sudah Terdaftar"?

Fotoyu menggunakan proteksi sidik jari digital (MD5 Hash). Jika foto tersebut pernah diunggah sebelumnya ke akun Fotoyu Anda, server akan secara otomatis menolak duplikasi agar foto tidak ganda di marketplace.

Apakah foto yang diunggah adalah file High-Resolution (Hi-Res)?

YA, 100% HI-RES ASLI. FotoSync PRO mengirimkan file biner asli tanpa penurunan kualitas ke AWS S3 Fotoyu. Ketika pembeli membeli foto Anda di Fotoyu, pembeli akan mendapatkan file Hi-Res asli tersebut.

Bagaimana cara mengaktifkan Lisensi Unlimited PRO?

Klik tombol status lisensi di sudut kiri bawah aplikasi (misal: FREE PLAN), pilih paket langganan yang Anda inginkan (1 Hari, 7 Hari, atau PRO), masukkan Master Key yang diberikan admin, lalu klik Aktifkan Lisensi.
